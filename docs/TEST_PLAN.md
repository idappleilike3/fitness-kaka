# TEST_PLAN.md — 測試計畫

**版本：** 0.1（2026-07-23）  
**產品：** 健身卡卡教練  

**規則：** 未實際執行測試不得宣稱「測試通過」。

---

## 1. 單元測試（優先）

| 模組 | 案例 |
|------|------|
| nutrition | BMR／TDEE／減脂熱量／蛋白 1.8 |
| quota | 分開扣圖／文／語音；跨日歸零 |
| newebpay | AES／SHA 組裝與驗簽（用假 Key 測向量） |
| meal confirm | pending→confirmed 才有 meal_records |

---

## 2. 整合測試（Webhook 模擬）

- 簽名錯誤 → 401  
- 重複 event_key → 不重複處理  
- 圖片成功路徑（可 mock OpenAI）  
- 額度用盡  
- 影片訊息 → 固定提示文案、0 次 OpenAI call  

---

## 3. 手動驗收（Phase 1）

| # | 步驟 | 期望 |
|---|------|------|
| 1 | 加好友 | 歡迎 + 建檔引導 |
| 2 | 完成建檔 | 顯示熱量／蛋白目標 |
| 3 | 傳食物照 | 分析結果 + 四按鈕 |
| 4 | 確認紀錄 | DB 有 meal；今日已攝取增加 |
| 5 | 不儲存 | DB 無 meal；額度已因分析扣過 |
| 6 | 打字飲食 | 同確認流程 |
| 7 | 「今天還能吃多少」 | 依個人當日數據 |
| 8 | 用完免費額度 | 升級引導 |
| 9 | 藍新測試付款 | Notify 後 +30 天 |
| 10 | 再送一次相同 Notify | 不加天、有 duplicate 紀錄 |
| 11 | 傳影片 | 提示用照片／文字；無 Vision |
| 12 | 傳語音（P1） | 提示尚未開放 |

---

## 4. 回歸（每次改金流／額度必跑）

- 建單金額不被前端篡改  
- Return 重整不開通兩次  
- 時區 Asia/Taipei 跨午夜額度
