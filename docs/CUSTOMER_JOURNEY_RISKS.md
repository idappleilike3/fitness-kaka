# 客戶旅程風險清單

> 目的：每次上線前，從會員實際使用流程檢查，不把問題留到客戶先踩到才補救

## Free → Plus（卡卡減脂）→ Pro（卡卡教練）

### 1. 加好友、建檔、第一次紀錄

- 會員加好友、追蹤或傳第一則訊息時，必須建立會員、免費方案與基本資料，並從 LINE Profile 寫入 `members.display_name`
- 後台必須可用顯示名稱或完整 LINE ID 找到會員；若 LINE 未提供名稱，要明確標示「未設定名稱」，不能看似搜尋失敗
- 建檔未完成時，先引導完成建檔；完成後才顯示個人熱量與蛋白質目標
- 聊天、問功能、貼圖不扣額度；免費會員只有「照片＋文字餐點分析」共用每日 5 次

### 2. 分析、修正、確認餐點

- 每次照片／文字／語音分析都要明示是「尚未儲存」；只有點「確認紀錄」才計入今日已攝取
- 在尚未確認的餐點後補充「加上／改成」時，必須更新同一餐，不能新增一筆或重複扣額度
- 今日已攝取為 0 時，要讓會員知道這是「已確認」數字，不是辨識失敗
- 額度用完時，免費會員可看到升級選項；付費會員只能看到額度重置時間與目前方案，不可再被推銷升級

### 3. 升級、付款與開通

- 會員輸入「升級」或按升級選單時，先以 `subscriptions.status=active` 且 `expires_at` 尚未到期的資料解析有效方案
- 有效付費方案的回覆必須顯示「你目前是卡卡減脂／卡卡教練，效期至 YYYY/M/D」，不顯示付款連結或升級推銷
- 藍新 Notify 驗簽成功才可標記訂單付款並寫入／延長訂閱；前端 Return 只能顯示結果，不能自行開通
- 重複 Notify、重送 webhook、同筆訂單重新整理都不得重複加天數
- 管理員手動開通要與付款開通共用同一套有效訂閱判定，並可延長既有有效效期

### 4. 已付費會員使用中

- 399：每日圖片 10、文字 30、語音 5；799：每日圖片 25、文字 60、語音 15；三種額度各自計算
- 到期或取消後才回到免費額度；過期資料不可繼續取得付費額度
- LINE 升級、說明、額度耗盡等訊息都要依目前方案調整語氣，且訊息結尾不使用句號
- 會員中心與 LINE 對「目前方案／到期日」的判定必須一致

### 5. 營運後台與客服追查

- 後台會員列表需顯示完整 LINE ID、顯示名稱、目前有效方案、狀態、開始日與到期日
- 後台要有「開通／訂閱紀錄」：每筆方案、狀態、開始日、到期日與來源訂單，讓客服能判斷贈送、付款、延長與過期
- 每次手動開通後，畫面須即時回顯結果；客服可用 JENNIE 或完整 LINE ID 再查一次 `plan_799`、狀態及效期
- 管理後台不可長期無密碼；暫時開放期間不得分享網址，並列為最高優先級安全債

## 上線前必查

1. 用免費帳號測：建檔、5 次共用分析、聊天不扣額度、確認後才進今日攝取
2. 用 399／799 帳號測：輸入「升級」、額度耗盡、照片、文字、語音與效期顯示
3. 用付款 sandbox 測：成功、失敗、重複 Notify、重新導回頁面
4. 後台用姓名及完整 LINE ID 搜尋，確認訂閱／開通紀錄可追溯
5. 每次部署後至少檢查 `/api/health`、LINE webhook callback 與一筆已付費帳號

## Batch 2（不阻塞本次修正）

- 年繳 Plus／Pro：先確認藍新商品、退款規則、續約／到期通知與方案資料後再重新開賣；在此之前維持 30 天一次付清，不讓年繳頁面部分上架或部分停售
- 恢復真正的管理員密碼／Session：設定強 `ADMIN_PASSPHRASE`、登入限流、登出與審計紀錄，關閉目前無密碼模式
- 健康聊天：定義非飲食問題的安全範圍、醫療風險拒答與轉介文案；不得把一般聊天誤當餐點分析或扣額度
