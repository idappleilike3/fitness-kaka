# 健身卡卡 v10 霓虹互動首頁設計

## 目標

保留健身卡卡 v10 已完成的健康減脂內容與指定卡卡教練素材，將首頁改造成女性友善的粉紫霓虹賽博朋克網站。頁面以格紋、玻璃資訊板與卡卡人物建立品牌辨識，同時保持營養資訊易讀、桌機與手機操作順暢。

## 視覺系統

- 背景：深葡萄紫 `#100718`，搭配粉紫透視格紋與低亮度青藍掃描光。
- 主色：卡卡桃粉 `#FF4FA3`、營養紫 `#9C6CFF`、提示青 `#6EE7FF`、LINE 綠 `#06C755`。
- 面板：半透明深紫玻璃，不使用純黑電競卡片；所有文字維持手機可讀對比。
- 主視覺：使用既有卡卡教練與餐點圖片，不生成或替換成其他人物。
- 記憶點：滑鼠移動時，格紋、光暈與主要卡片產生不同速度的視差；卡片接近游標時有 5～7 度 3D 傾斜與光邊。

## 頁面與互動

- 首頁 Hero 保留指定卡卡教練圖，背景加入透視格紋、掃描線與滑鼠視差。
- 主要圖文區保留每段對應圖片，缺少圖像的功能卡改用已有卡卡／餐點素材呈現，不用純圖示代替。
- 外食版、超商版、居家版改成真正的互動分頁。切換時同步更新卡卡情境圖、推薦組合、熱量、蛋白質與當餐指引。
- 桌機採圖片與資料並排，手機改為單欄、可水平操作的分頁，不依賴 hover 才能理解內容。
- 滑鼠卡片採 pointer 3D tilt；觸控裝置只保留按壓與緩慢漂浮。`prefers-reduced-motion` 關閉視差、漂浮與大幅轉場。

## 免費卡卡問答機器人

- 固定右下角 Q 版卡卡入口，使用既有卡卡教練圖片裁切成可愛圓形角色，不新增生成圖。
- 提供健康減脂、今天怎麼吃、外食／超商／居家、蛋白質、7 天體驗、方案等預設問題。
- 自由輸入只在瀏覽器端以關鍵字與同義詞比對固定答案，不呼叫 OpenAI 或任何付費 API。
- 回答前顯示短暫「卡卡正在想」，回答後顯示延伸問題。無法辨識或涉及醫療診斷時，引導至 `https://lin.ee/5rxQDpa`。
- 進站只顯示視覺招呼；提示音必須在瀏覽器允許且使用者互動後播放。提供清楚的有聲／靜音按鈕，偏好保存在 `localStorage`。
- 對話框支援鍵盤、焦點樣式、ARIA 標籤；手機使用安全區內的底部面板。

## 技術邊界與驗收

- 不修改金流、會員資料庫、後台、LINE OA 發布或既有營養計算服務。
- 不新增付費服務、API 金鑰或聊天後端路由；訪客文字不離開瀏覽器。
- 行為測試覆蓋三情境切換、規則命中、同義詞、醫療攔截、未知問題、LINE 引導、聲音開關與無 API 請求。
- 必須通過首頁相關測試、TypeScript／Next.js 正式建置，並以桌機和手機瀏覽器檢查版面、圖片與互動。
