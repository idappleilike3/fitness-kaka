## 2. 三階段路線圖

### Phase 1 — 驗證市場（可測試、可收費 MVP）

**目標：** 獲取首批付費客，驗證「飲食紀錄 + 熱量管理」是否願意付 399。

**包含：**

- LINE 加入 → 自動建立會員（記錄 `line_user_id`）
- 會員設定：性別、年齡、身高、體重、目標體重、活動量、健身頻率、目標（減脂／增肌／維持）
- 系統計算：BMI、BMR、TDEE、每日熱量與蛋白質／碳水／脂肪目標
- 圖片飲食辨識（OpenAI Vision）+ 確認／修改份量／重新辨識／不儲存
- 文字飲食分析 + 確認後寫入
- 每日熱量管理與個人化問答（今日剩餘、蛋白質是否夠等）
- 方案：免費 + NT$399／30 天
- 藍新一次付清 + Notify 更新訂閱
- LIFF 基礎總覽：今日熱量、剩餘、蛋白質、飲食紀錄、訂閱狀態、條款隱私
- 安全：Webhook 驗簽、額度、去重、usage log、免責聲明

**明確排除：** 語音、課表生成、定期定額、週報告、邀請好友、分潤後台。

### Phase 2 — 正式版

**目標：** 提高留存、完整訂閱體驗。  
**詳見：** `docs/PHASE2_PLAN.md`

- 語音飲食紀錄（免費 0；399／799 分開額度；**用才分析，非每天自動**）
- 上架 799
- 進階健身建議（**模板優先**，每週／按需，非每天全員 AI）
- LIFF 7／30 天圖表、體重趨勢（**讀 DB 畫圖，幾乎不花 OpenAI**）
- 信用卡定期定額（需資格；未到位則一次付 + 到期提醒）

**不做：** 每天自動長篇 AI 報告、免費語音、影片算熱量。

### Phase 3 — 爆款版

**目標：** 病毒式增長。

- 每週 AI 檢討報告（短格式、控 token）
- 邀請好友送額度（Referral）
- 教練／營養師分潤合作後台

## 3. 系統架構（摘要）

```
LINE 使用者
  → Vercel (Next.js API)
      → LINE Webhook（驗簽、去重、額度）
      → OpenAI（Vision／Chat；P2 Whisper）
      → Supabase（會員、紀錄、訂單、額度）
  → LIFF（總覽／付款入口）
  → NewebPay MPG（建立訂單 → 付款 → Notify 授權威）
```

詳見 `docs/SYSTEM_ARCHITECTURE.md`。
