# V10 首頁翻轉與 LINE「如何開始」設計

日期：2026-08-10

## 已確認需求

### V10 首頁第一張互動
- 第一張內容維持 V10 原本的「兩張照片／正反面翻轉」設計，不改成單張靜態圖片。
- 電腦：滑鼠移入或操作時可看到翻轉效果。
- 手機：點擊卡片切換正面／背面。
- 正面與背面尺寸一致，圖片不可因翻面被裁掉或消失。
- 保留既有 V10 視覺與使用者提供的圖片，不另做一套首頁風格。

### LINE「如何開始」
「如何開始」不是六張教學卡，也不是直接把使用者丟到網頁。

點擊後流程：
1. 卡卡先用短句說明：加入 LINE 後會一步一步帶著使用者開始，不需要先看複雜網頁。
2. 接著顯示一張 LINE Flex 圖文按鈕卡。
3. 圖文按鈕卡固定三個選項：
   - 開始 7 天免費體驗
   - 先看看怎麼使用
   - 我已經是會員

### 三個按鈕行為
- 「開始 7 天免費體驗」：先在 LINE 內詢問使用者是否確定開始，再進入建檔／體驗流程，不直接跳銷售頁。
- 「先看看怎麼使用」：在 LINE 內以簡短、分段、易懂的圖文按鈕方式解釋核心操作，再引導使用者開始；避免密集長文。
- 「我已經是會員」：進入 LINE/LIFF 會員登入與身份辨識，成功後導向會員中心，不重新要求已完成會員註冊。

## 驗收標準
- 首頁第一張可實際正反翻轉，且確實有兩張／兩面內容。
- 手機與桌機都能操作翻轉。
- LINE 點「如何開始」只出現一張主要圖文按鈕卡，不再一次送六張卡。
- 三個按鈕均可按，且各自走正確流程。
- 「免費開始」不直接進複雜網頁。
- 已有會員不被重新要求註冊。
