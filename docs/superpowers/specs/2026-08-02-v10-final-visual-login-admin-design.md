# 健身卡卡 V10 最終視覺、LIFF 登入與後台設計

## 目標

保留 V10 商業功能，恢復先前完成的新版首頁圖片，並統一手機與桌面版的圖片尺寸、欄寬與左右留白。會員登入直接進入 LIFF，不經過 LINE OA 加好友中間頁。管理後台改為深色科技風。

## 首頁圖片與版面

- 使用已保存於 V10 歷史版本的新版圖片資源。
- 桌面雙欄區塊一律 1:1 等寬，左右欄使用相同高度基準。
- 同一列圖片使用一致長寬比、圓角與裁切方式（object-fit: cover）。
- 手機版改為單欄後，所有圖片寬度一致，左右留白一致，禁止一張橫版、一張直版造成高度跳動。
- 菜單、運動、30 天挑戰與停滯期切換圖均使用固定圖片容器，切換時版面不位移。

## 會員登入

- 首頁會員登入按鈕直接導向 `https://liff.line.me/{LIFF_ID}`。
- LIFF 頁面初始化 LINE LIFF SDK；未登入時直接執行 `liff.login()`。
- 登入成功後由 `liff.getProfile()` 取得 LINE User ID，再載入會員摘要。
- 不再先導向 LINE OA 首頁，也不要求使用者點第二次。
- 若環境缺少 LIFF ID，顯示明確設定錯誤，不默默導向其他頁面。

## 管理後台

- 全頁使用深黑、墨綠背景。
- 卡片、表格、輸入框與分頁使用深色高對比設計。
- 主操作按鈕使用亮綠色；次要操作使用深綠描邊。
- 保留原本會員、付款、方案、關懷、成交與系統狀態功能，不改動資料邏輯。

## 驗收

- Vercel Preview Build 必須 READY。
- 首頁新版圖片可正常載入。
- 桌面雙欄左右等寬；手機所有圖片與左右留白一致。
- `/member-login` 直接跳 LIFF。
- `/admin` 登入前後均为暗色系。
