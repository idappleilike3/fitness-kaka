# 卡卡免費規則式問答機器人設計

## 目標

在健身卡卡 v10 首頁加入一個看起來自然、有互動感的 Q 版卡卡問答機器人，但完全不呼叫付費 AI API。訪客可點選問題或自由輸入，系統只在瀏覽器內以預設答案、關鍵字與近似詞比對回答。

## 互動方式

- 首次開啟顯示卡卡招呼、短動畫與可選提示音；使用者可隨時開啟或靜音。
- 預設問題涵蓋健康減脂、今天怎麼吃、外食／超商／居家選餐、蛋白質、7 天體驗、方案與使用方式。
- 自由輸入會先正規化文字，再依關鍵字群組與優先順序選出最適合的預設回答。
- 回答前顯示短暫「卡卡正在想」狀態，回答後提供 2～3 個延伸問題，營造連續對話感。
- 無法辨識、涉及疾病／診斷、或需要高度個人化時，不亂猜；改提供相關選項並引導至健身卡卡 LINE：`https://lin.ee/5rxQDpa`。

## 技術邊界

- 不呼叫 OpenAI、其他生成式 AI 或任何按量付費服務。
- 不新增 API 金鑰，不將訪客問題送到伺服器或第三方。
- 規則與回答資料獨立於視覺元件，方便日後新增問題而不改聊天介面。
- 聊天紀錄只保留在目前瀏覽器畫面，重新整理後清除。
- 提示音使用本地短音效或 Web Audio；遵守瀏覽器自動播放限制，失敗時保持靜音且不阻擋操作。

## 視覺與無障礙

- Q 版卡卡入口固定於畫面右下角，配合粉紫霓虹賽博朋克版型。
- 桌機支援滑鼠懸浮、輕微 3D 傾斜與光暈；手機改用觸控回饋，避免游標專屬效果。
- 對話框在桌機為浮動面板，手機為不超出安全區的底部面板。
- 支援鍵盤操作、可辨識的按鈕標籤、焦點樣式及 `prefers-reduced-motion`。

## 安全回答規則

- 不提供疾病診斷、藥物調整、極端節食或保證減重效果。
- 健康與營養內容只提供一般生活指引；特殊疾病、孕期、飲食障礙或身體不適會建議諮詢醫師／營養師。
- 方案與體驗內容只使用網站目前正式資料，避免回答不存在的權益。

## 驗收

- 程式搜尋與網路攔截測試可證明聊天流程沒有 AI API 請求。
- 點選問題、自由輸入命中、同義詞命中、無法辨識、健康安全攔截及 LINE 引導均有自動化測試。
- 音效開關、開啟／關閉聊天、延伸問題與手機版操作正常。
- 正式建置與既有首頁回歸測試通過。
