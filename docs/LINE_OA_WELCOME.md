# LINE 官方帳號歡迎訊息（手動貼上用）

Webhook `follow` 會先送歡迎圖文卡，再自動送出「1 分鐘了解你」與四選一目標問卷。可在 LINE Official Account Manager 保留相同品牌視覺，但不要另外開啟重複的加入好友回覆。

## 重要提醒

若 **Messaging API webhook 已會在加入好友時回傳歡迎訊息**，請在 OA 後台 **關閉「加入好友自動回應」**（或刪除重複歡迎規則），否則使用者會收到兩則幾乎相同的訊息。

圖文選單與關鍵字回應也請避免再回覆歡迎／怎麼用／升級等與 webhook 重疊的內容。詳見 [LINE_OA_SETUP.md](./LINE_OA_SETUP.md)。

## 歡迎訊息全文（可直接複製）

```
嗨，我是卡卡
不用節食，也不用每天自己算熱量

拍下每一餐，我陪你完成 30 天減脂挑戰

你可以馬上試：
・傳食物照片 → AI 估熱量（確認後才存檔）
・打字告訴我吃了什麼
・問「今天還能吃多少」看剩餘

想正式開始挑戰，跟我說：
「我要參加三十天減脂挑戰」

輸入「怎麼用」看完整說明
升級方案可回「升級」（體驗／記錄／陪伴）

⚠️ AI 推估可能有誤差，結果非醫療診斷
```

## 備註

- 每則 LINE 氣泡結尾不要加句號「。」或「。」
- 歡迎訊息結尾是「診斷」，不是「診斷。」
