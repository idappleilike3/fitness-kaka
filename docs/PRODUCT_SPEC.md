## 1. 目標客群

- 想減脂的人

- 外食族

## 3. Phase 1 功能清單（必須有）

### 3.1 LINE 會員

| 功能 | 說明 |
|------|------|
| 加入好友／首次訊息 | 自動建立 `members`（以 `line_user_id` 唯一） |
| 導引建檔 | 收集：性別、年齡、身高、體重、目標體重、活動量、健身頻率、目標類型 |
| 營養目標計算 | BMI、BMR、TDEE、每日熱量、蛋白質／碳水／脂肪目標 |
| 可修改資料 | 使用者可再次進入設定更新體重等 |

**活動量（建議選項）：** 久坐、輕度、中度、高強度  
**目標類型：** 減脂、增肌、維持體重

**計算規則（拍板用公式，實作不可擅自改商業邏輯）：**

- BMI = 體重(kg) / (身高m)²
- BMR：Mifflin-St Jeor  
  - 男：`10*kg + 6.25*cm - 5*age + 5`  
  - 女：`10*kg + 6.25*cm - 5*age - 161`
- TDEE = BMR × 活動係數（久坐 1.2／輕 1.375／中 1.55／高 1.725）
- 每日建議熱量：減脂 ≈ TDEE×0.8；增肌 ≈ TDEE×1.1；維持 ≈ TDEE
- 蛋白質(g)：減脂／增肌 ≈ 體重(kg)×1.6～2.0（Phase 1 定 **1.8**）；維持 ≈ 1.4
- 脂肪(g)：熱量×0.25／9  
- 碳水(g)：剩餘熱量／4  

### 3.2 拍照辨識飲食

1. 使用者傳圖片  
2. Webhook 驗簽 → 檢查額度 → 下載圖片（限制大小）→ OpenAI Vision  
3. 回覆辨識結果（標示 AI 推估）+ 按鈕：確認紀錄／修改份量／重新辨識／不儲存  
4. **僅在「確認紀錄」後**寫入 `meal_records`／`meal_items` 並更新當日 summary  
5. 扣圖片額度的時機：**成功完成一次 Vision 分析時**（重新辨識再扣一次；「不儲存」已分析過仍算用過額度）

### 3.3 文字飲食紀錄

- 使用者輸入如：「我剛剛吃了一碗牛肉麵和一顆滷蛋」
- AI 解析食物與營養 → 同樣確認流程 → 確認後寫入  
- 扣文字飲食分析額度

**不扣額度的互動（Phase 1）：** 歡迎、建檔問答、按鈕點擊（非重新辨識）、查詢「今天還能吃多少」、訂閱／客服導引、LIFF 開啟。

### 3.4 每日熱量管理

系統記錄（當日）：各餐／點心、總熱量、蛋白質、碳水、脂肪。  
（飲水量、運動消耗：Phase 1 可先不做或僅預留欄位。）

可回答（必須依該會員當日資料）：

- 我今天還能吃多少？
- 今天蛋白質夠嗎？
- 晚餐建議吃什麼？（一般性建議 + 剩餘額度，非醫療）
- 今天有沒有超標？
- 我現在可以吃麥當勞嗎？（依剩餘熱量／蛋白給參考，非鼓勵或禁止的醫療指示）

### 3.4.1 影片訊息（不做分析）

使用者傳影片時：**不下載、不呼叫 OpenAI、不扣額度**。  
回覆提示改用照片／文字；付費會員可另用語音訊息記飲食。

Phase 3 影片用途：Form Check（動作糾正），非算熱量。

### 3.4.2 語音飲食紀錄（Phase 2 已開）

1. 使用者傳 LINE 語音（≤60 秒；超過則拒絕且**不呼叫 Whisper**）  
2. 檢查**語音額度**（與文字分開）→ 下載 → Whisper 轉文字 → 同一套飲食 JSON 分析  
3. pending 確認後才寫入  
4. 扣**語音**額度 1 次（不扣文字）  
5. 免費語音 = 0 → 升級 CTA；399＝5／天；799＝15／天  

### 3.5 付費

- 免費 + **NT$399／30 天** + **NT$799／30 天**（一次付清；語音上線後 799 已上架）
- 藍新 MPG；Notify 成功後延長 `subscriptions.expires_at` +30 天

### 3.6 LIFF 基礎總覽

至少顯示：

- 今日熱量、剩餘熱量、今日蛋白質  
- 飲食紀錄（當日）  
- 訂閱方案狀態、到期日  
- 前往付款  
- 取消訂閱說明（Phase 1：一次付清無自動續扣，說明「到期後停止進階額度」即可）  
- 隱私權政策、使用條款連結  

Phase 1 可不做：完整體重曲線、健身計畫頁、付款歷史細表（可先顯示最近一筆訂單狀態）。

## 5. 回覆格式範例（飲食辨識）

```
餐點辨識結果（AI 推估）

雞胸肉：約 150 克
白飯：約 1 碗
青菜：約 1 份

預估總熱量：620 kcal
蛋白質：48g
碳水：70g
脂肪：15g

今日已攝取：1,450 kcal
今日剩餘：550 kcal
蛋白質還差：35g

⚠️ AI 圖片辨識可能有誤，請依實際份量調整。
此結果非醫療或營養診斷。
```

按鈕：確認紀錄｜修改份量｜重新辨識｜不儲存
